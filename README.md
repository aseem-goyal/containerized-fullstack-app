# Containerized Full-Stack Application

A full-stack web application built using Flask and Node.js,
containerized using Docker and Docker Compose.

## 🚀 Tech Stack

- Python
- Flask
- Node.js
- Express.js
- Docker
- Docker Compose
- Jenkins
- Git & GitHub

## 🏗️ Architecture

The application consists of a Node.js frontend and Flask backend,
with both services running in separate Docker containers.

```text
User
  │
  ▼
Node.js / Express Frontend
  │
  ▼
Flask Backend API
  │
  ▼
Docker Containers
```
